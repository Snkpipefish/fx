# Skrifter

Selvhostet, så siden ikke er avhengig av Google Fonts.

| Fil | Familie | Akser | Lisens |
|---|---|---|---|
| `fraunces-latin-var.woff2` | Fraunces (Undercase Type) | variabel: vekt 500–600, optisk størrelse 9–144 | SIL Open Font License 1.1 (`OFL-Fraunces.txt`) |
| `inter-latin-var.woff2` | Inter (Rasmus Andersson) | variabel: vekt 400–700 | SIL Open Font License 1.1 (`OFL-Inter.txt`) |

Filene er Googles latin-subsett (unicode-range U+0000-00FF, U+0131, U+0152-0153, U+02BB…), hentet 25. september 2026 fra fonts.gstatic.com med en nettleser-User-Agent, som gir ferdige woff2-subsett uten behov for `pyftsubset`. Hent på nytt ved behov med samme fremgangsmåte og oppdater `@font-face` i `css/style.css`.
